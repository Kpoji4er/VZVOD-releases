## Запуск

1. Скачайте ZIP и полностью распакуйте его в отдельную папку.
2. Запустите `VZVOD.exe`. Файлы `VZVOD.pck` и `vzvod_geometry.windows.template_release.x86_64.dll` должны оставаться рядом.
3. Начните с операции «Обучение · Полигон». Нажмите «Готов», затем «Начать операцию». Пробел — тактическая пауза.

[Изменения и известные ограничения демоверсии](https://github.com/Kpoji4er/VZVOD-releases/releases/tag/VZVOD-20261024-r2-win64).

Для r2 проверены ресурсы после упаковки, семь операций и запуск экспортированного EXE. Полный регрессионный и сетевой наборы не запускались; стабильные 60 FPS в тяжёлом бою и на карте 200×200 не подтверждены.

## Сообщить об ошибке
