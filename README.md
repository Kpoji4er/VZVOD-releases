# VZVOD

Тактическая игра в реальном времени с паузой. Публичные сборки для Windows x64.

**[Скачать игру](https://github.com/Kpoji4er/VZVOD-releases/releases)**

## Запуск

1. Откройте страницу выпуска и скачайте архив `VZVOD-…-win64.zip`.
2. Полностью распакуйте архив в отдельную папку.
3. Запустите `VZVOD.exe`. Файлы `VZVOD.pck` и DLL должны оставаться рядом.
4. Начните с операции «Обучение · Полигон». Нажмите «Готов», затем «Начать операцию». Пробел — тактическая пауза.

Рядом с архивом опубликована контрольная сумма SHA256.

## Статус

Игра находится в разработке. Выпуски с отметкой Pre-release — кандидатные сборки для плейтестов. Известные ограничения и изменения описаны на странице каждого выпуска. В текущей сборке производительность пятой миссии остаётся ограниченной.

Об ошибках можно сообщать через [Issues](https://github.com/Kpoji4er/VZVOD-releases/issues). Укажите версию, миссию и шаги воспроизведения. Начиная с r2, F9 открывает окно отчёта. Введите описание и нажмите «Отправить в GitHub»: в браузере откроется заполненная форма Issue. Войдите в GitHub и подтвердите публикацию; снимок добавьте вручную через «Папку снимка». При проблемах с браузером используйте «Копировать отчёт». Фоновая отправка не выполняется.

Этот репозиторий содержит описания и готовые сборки. Исходный код игры здесь не публикуется.
